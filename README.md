# EDA_IITSTUDENTS_DATASET
This project involves performing EDA on a dataset of 200,000 student records from 2016 to 2022, containing 10 features such as:
-Admission Year
-Field of Study
-Current Semester
-Fees and Discounts
-Specialization and More

# 🧹 Data Cleaning
-Handled missing values and null entries
-Formatted date columns (e.g., Date of Birth, Admission Year)
-Standardized student information fields

# 📊 Data Analysis & Visualization
-Used Pandas and NumPy for data manipulation
-Created visualizations using Matplotlib and Seaborn
-Plotted bar charts and histograms to show trends in semester progression, fee structures, and discount patterns
